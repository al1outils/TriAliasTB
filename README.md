# TriAliasTB

Open-source Windows utility that sorts Thunderbird email aliases
alphabetically while preserving the original order of mail accounts.

## Download

Download **TriAliasTB.exe** from the latest GitHub Release.

## Windows SmartScreen warning

When downloading and launching `TriAliasTB.exe` for the first time, Microsoft Defender SmartScreen may display a warning stating that the application is “unrecognized”.

This warning may appear because the application is new and has not yet built a reputation with Microsoft. To launch TriAliasTB, click **More info**, then **Run anyway**.

## Features

-   Alphabetical sorting of Thunderbird aliases.
-   Preserves the primary identity.
-   Keeps the original order of mail accounts.
-   Automatic backup of `prefs.js`.
-   Automatic Thunderbird profile detection.
-   Automatic detection of Thunderbird running state.
-   Standalone executable with no external dependencies.

## Compatibility

  System            Status
  ----------------- --------
  Windows 10 22H2   ✅
  Windows 11 25H2   ✅

## How to use

1.  Close Thunderbird.
2.  Launch `TriAliasTB.exe`.
3.  Select the profile if needed.
4.  Check **Mailboxes to sort**.
5.  Click **Sort aliases**.

## Safety

The application is portable and does not modify the Windows Registry or
`%APPDATA%`.
