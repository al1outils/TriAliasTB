# TriAliasTB

Outil libre pour trier automatiquement les alias Thunderbird par ordre
alphabétique, sans modifier l'ordre des boîtes mail.

## Téléchargement

Téléchargez **TriAliasTB.exe** depuis la dernière version (Release) du
dépôt GitHub.

## Avertissement Windows SmartScreen

Lors du premier téléchargement et lancement de `TriAliasTB.exe`, Windows Defender SmartScreen peut afficher un message indiquant que l’application est « non reconnue ».

Cette alerte peut apparaître parce que l’application est nouvelle et n’a pas encore acquis de réputation auprès de Microsoft. Pour lancer TriAliasTB, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Fonctionnalités

-   Tri alphabétique des alias Thunderbird.
-   Conservation de l'identité principale.
-   Aucune modification de l'ordre des boîtes mail.
-   Sauvegarde automatique de `prefs.js`.
-   Détection automatique des profils Thunderbird.
-   Détection automatique de Thunderbird ouvert/fermé.
-   Fonctionnement autonome, sans dépendance externe.

## Compatibilité

  Système           Validation
  ----------------- ------------
  Windows 10 22H2   ✅
  Windows 11 25H2   ✅

## Utilisation

1.  Fermez Thunderbird.
2.  Lancez `TriAliasTB.exe`.
3.  Choisissez le profil si nécessaire.
4.  Vérifiez le nombre de **Boîtes à trier**.
5.  Cliquez sur **Trier les alias**.

## Sécurité

Avant toute modification, TriAliasTB crée automatiquement une sauvegarde
de `prefs.js`.

Le programme est portable : il ne modifie ni le Registre Windows ni
`%APPDATA%`.
